# glance 画面設計

作成日: 2026-11-26
状態: 初版（実装前）。1番目の段階（リアルタイム画面）で作る3画面を書く。全体サマリー・チャット・ダッシュボードの画面は、その段階の前に足す。

画面の機能は [overview.md](overview.md) §4、API は [technical_design.md](technical_design.md) §6、リアルタイムのデータは [data_sources.md](data_sources.md) §5。

---

## 1. 共通

- **ヘッダー**: 左に「Glance」とメニュー（リアルタイム、サイト設定）、右にログイン中のメールアドレスとログアウト。全体サマリー・チャット・ダッシュボードは、作った段階でメニューに足す。
- **時刻**: すべて日本時間で出す。
- **スマホ**: 表は横にスクロールさせる。グラフは画面の幅に合わせて縮める。
- **文字の表示**: タイトルなど取り込んだ文字は、そのまま文字として出す（HTML として描画しない。[overview.md](overview.md) §5）。

## 2. ログイン（`/login`）

```
┌──────────────────────────────┐
│            Glance              │
│                                │
│     [ Google でログイン ]        │
│                                │
│  （エラーのときだけ、ここに出す）   │
└──────────────────────────────┘
```

| 場合 | 出す文 |
|---|---|
| 許可リストにないアカウント | このアカウントは使えません。別の Google アカウントでログインしてください。 |
| 同意画面で中止した | ログインを中止しました。 |
| 許可が切れた（`reauth_required`） | Google の許可が切れました。ログインし直してください。 |
| その他 | ログインできませんでした。時間をおいてもう一度試してください。 |

## 3. リアルタイム（`/`）

ログインした後に最初に開く画面。

```
┌ Glance  リアルタイム  サイト設定 ─────────────────── user@… ログアウト ┐
│                                                                      │
│ リアルタイム（直近30分）                    14:32:05 に取得  [ 更新 ]    │
│ ⓘ ボットを含む数字です（除外できません）。日次の数字とは比べられません。…    │
│                                                                      │
│ ┌ サイト別 ────────────────────────────────────────────────────┐ │
│ │ サイト      │ PV 30分 │ PV 5分 │ UU 30分 │ UU 5分 │ キーイベント │ │
│ │ ● LogiShift │     120 │     18 │      45 │      9 │          2 │ │
│ │ ● TechShift │ 取得できませんでした（時間切れ）                   │ │
│ │ ● ConShift  │       … │      … │       … │      … │          … │ │
│ │ 合計        │     300 │     40 │     110 │     21 │          3 │ │
│ └──────────────────────────────────────────────────────────┘ │
│                                                                      │
│ 出すサイト: ☑ LogiShift ☑ TechShift ☑ ConShift ☐ FinShift ☑ LeadHub  │
│                                                                      │
│ ┌ 分ごとの推移   [ PV ] [ UU ] ────────────────────────────────┐ │
│ │                                                        ─ 20  │ │
│ │   ╱╲    ╱╲___                                          ─ 10  │ │
│ │ ╱   ╲__╱      ╲___╱╲                                   ─ 0   │ │
│ │ 30分前                  15分前                       今      │ │
│ └──────────────────────────────────────────────────────────┘ │
│                                                                      │
│ ┌ いま読まれている記事（選んだサイトの PV の上位20）─────────────┐ │
│ │ #  │ タイトル                         │ サイト    │ PV 30分 │ UU 30分 │ │
│ │ 1  │ 記事のタイトル                    │ LogiShift │      12 │       8 │ │
│ │ …                                                              │ │
│ └──────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────────────┘
```

（数字は例）

**各部**

- **UU**: GA4 のアクティブユーザー（`activeUsers`）。リアルタイム API で取れるユーザー数はこれだけ。
- **取得した時刻と「更新」**: 開いたときに1回取る。あとは「更新」を押したときだけ取り直す。取っている間はボタンを押せなくし、前の数字は薄くして残す。
- **注記**: [data_sources.md](data_sources.md) §5 の画面の注記を、いつも出す（ボットを含むこと、PV を主に見ること、国を出さないこと、取得した時刻の数字であること）。長い部分は「詳しく」で開く。
- **サイト別の表**
  - 並びはサイト設定の並び順。サイト名の前の丸は、グラフの線の色。
  - 合計の行は、取得できたサイトだけで出す。取得できなかったサイトがあるときは「（1サイトを除く）」と添える。
  - UU の合計は、サイトごとの人数を足したもの。
- **出すサイト**: グラフの上に、サイトごとのチェックボックスを並べる。**分ごとの推移と、いま読まれている記事の両方に効く。** サイト別の表は変わらない（いつも全サイトを出す）。
  - チェックボックスの枠の色を、そのサイトの線の色にする。グラフの凡例を兼ねるので、グラフには別に凡例を出さない。
  - 初めは全部オン。「更新」を押しても選んだ状態は保つ。画面を開き直すと全部オンに戻る。
  - 切り替えは画面の中だけで行い、API は呼ばない。
  - 取得できなかったサイトは、チェックボックスを押せなくする。
  - 全部オフにしたら、グラフと記事の一覧の枠に「サイトを選んでください」と出す。
- **分ごとの推移**: 折れ線で、選んだサイトごとに1本。横軸は30分前から今まで。縦軸の目盛りは、出しているサイトに合わせて付け直す。
  - **指標は PV と UU を切り替える**（グラフの上のボタン。初めは PV）。切り替えは画面の中だけで行い、API は呼ばない。「更新」を押しても選んだ指標は保つ。
  - 分ごとの UU は、その1分の間に来た人数。同じ人が何分にもまたがるので、分ごとの UU を足しても30分の UU にはならない（表の UU は別に取った値）。
- **いま読まれている記事**: 選んだサイトの記事をまとめて、PV の多い順に20件。PV と UU を並べて出す。タイトルはそのまま出し、長いものは省略して、ホバーで全文を出す。
  - サイトごとの上位20件（API の応答）から、画面で選んだサイトの分を合わせて並べ直す。どのサイトの組み合わせでも、上位20件はこの中に入る。
- **「AI に聞く」**: 5番目の段階（チャットを作るとき）に、「更新」の隣に足す（[ai_query_design.md](ai_query_design.md) §6.3）。

**状態ごとの出し方**

| 状態 | 出し方 |
|---|---|
| 初めて取っている間 | 表・グラフの枠だけ出し、中身は読み込み中の表示 |
| 一部のサイトが失敗 | そのサイトの行に「取得できませんでした（理由）」。理由は時間切れ、権限がない、上限に当たった、その他 |
| 全サイトが失敗 | 表の上に「取得できませんでした。時間をおいて更新してください」 |
| 許可が切れた | ログイン画面へ移し、理由を出す（§2） |
| サイトが1つもない | 「サイト設定から GA4 のプロパティを追加してください」と、サイト設定への案内 |

## 4. サイト設定（`/settings/sites`）

```
┌ Glance  リアルタイム  サイト設定 ─────────────────── user@… ログアウト ┐
│                                                                      │
│ サイト設定                                        [ サイトを追加 ]     │
│                                                                      │
│ ┌──────────────────────────────────────────────────────────┐ │
│ │ 並び │ 名前（編集できる） │ GA4 プロパティ ID │ タイムゾーン │      │ │
│ │ ↑↓  │ LogiShift         │ 123456789        │ Asia/Tokyo  │ 削除 │ │
│ │ ↑↓  │ TechShift         │ …                │ …           │ 削除 │ │
│ └──────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────────────┘
```

（プロパティ ID は表示の例）

- **サイトを追加**: ログインしたアカウントが見られる GA4 のプロパティを、アカウントごとにまとめて一覧で出す。選ぶとサイトとして追加する。名前とタイムゾーンはプロパティから取る。追加済みのプロパティは選べなくする。
- **名前**: その場で編集できる。初めはプロパティの名前。
- **並び**: リアルタイムの表とグラフの色の順になる。
- **削除**: 確かめてから消す。
- Search Console・Bing の紐づけは、2番目の段階でこの画面に足す。

## 5. グラフの見た目（GA4 に近づける）

Recharts の設定。[overview.md](overview.md) §3。

| 項目 | 設定 |
|---|---|
| 補助線 | 横だけ。薄いグレー |
| 縦軸 | 目盛りは右側。軸の線は引かない |
| 線 | 細め。普段は点を出さず、ホバーした点だけ丸を出す |
| 比較期間 | 破線（2番目以降の段階で、比較のあるグラフに使う） |
| ホバー | 縦線を引き、その時点の全系列の値を1枚のカードに並べる（系列の色の丸、名前、値）。カードは React のコンポーネントで書く |
| 凡例 | グラフの上に、色の丸と名前を横に並べる。リアルタイムの分ごとの推移（§3）では、グラフの上の「出すサイト」のチェックボックスが凡例を兼ねる |
| 色 | shadcn/ui の Chart の色（`--chart-1`〜`--chart-5`）を、サイトの並び順に割り当てる。6サイト目からの色は、そのときに足す |
| 動き | 描き始めのアニメーションは切る |

画面全体の色・文字・余白などの決まりは、デザインガイドライン（design_guideline.md。まだ作っていない）で決める。
