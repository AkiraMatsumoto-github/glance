# glance デザインガイドライン

作成日: 2026-11-26
状態: 初版。管理コンソールのすべての画面に当てる。

色・文字・余白・部品・グラフの描き方・書き方の決まり。画面ごとの配置は [screen_design.md](screen_design.md)、技術は [technical_design.md](technical_design.md)。

---

## 1. 方針

1. **数字が主役。** 飾りは置かない。見出し・枠・区切りは、数字を読む順番を示すためにだけ使う。
2. **色はデータのためだけに使う。** 画面の地・枠・ボタン・文字は、墨色と灰色だけにする。鮮やかな色は、サイトを見分けるための色（§2.2）と、状態を知らせる色（§2.3）だけ。
3. **GA4 に慣れた人が迷わない読み方にする。** 白い面、横だけの補助線、右の縦軸、ホバーで出るカード。ただし、GA4 の見た目（Google の青、Google の書体、ロゴ）はまねしない。外販するので、Google の製品に見えてはいけない。
4. **色だけに頼らない。** サイトは、色の丸と名前を必ず並べる。状態は、色とアイコンと文で示す。

## 2. 色

### 2.1 画面の色

| 名前（CSS 変数） | 値 | 使うところ |
|---|---|---|
| `--page` | `#f5f6f8` | 画面の地 |
| `--surface` | `#ffffff` | 表・グラフ・ダイアログの面 |
| `--border` | `#e2e5e9` | 面の枠、表の区切り（1px） |
| `--grid` | `#eceef1` | グラフの補助線 |
| `--axis` | `#cdd2d8` | グラフの軸の線 |
| `--hover` | `#f0f2f5` | 行・控えめなボタンのホバー |
| `--ink` | `#1c2330` | 本文、見出し、主なボタンの面 |
| `--ink-2` | `#4a5462` | 補足の文、表の見出し |
| `--ink-3` | `#646d79` | 目盛り、時刻、注記 |

文字の色（`--ink`・`--ink-2`・`--ink-3`）はすべて、白い面と画面の地の両方で 4.5:1 以上（`--ink-3` は地の上で 4.85:1）。

### 2.2 サイトの色

サイトを見分けるための色。8色を、サイト設定の並び順に1色目から割り当てる。

| 順 | 名前 | 値 | 白い面とのコントラスト |
|---|---|---|---|
| 1 | 深い青 | `#2552aa` | 7.6:1 |
| 2 | 黄土 | `#c28412` | 3.1:1 |
| 3 | 青緑 | `#14938d` | 3.8:1 |
| 4 | 薄紫 | `#a67ad6` | 3.5:1 |
| 5 | ワイン | `#922d55` | 8.0:1 |
| 6 | 橙 | `#d97230` | 3.3:1 |
| 7 | 深緑 | `#046a2f` | 6.8:1 |
| 8 | 藤 | `#8285eb` | 3.3:1 |

**検査の結果**（dataviz の `validate_palette.js`、白い面）

- 8色・隣り合う組: すべての検査に通る。色覚の型を模した差は最小 ΔE 10.3（目標 8 以上）、ふつうの見え方の差は最小 20.8（下限 15）、コントラストは全色 3:1 以上。
- 最初の5色・すべての組: すべての検査に通る（最小 ΔE 10.3・20.8）。今の5サイトは、どの2本の線が並んでも見分けられる。
- 明るさをわざとずらしている（深い青・ワイン・深緑は暗く、黄土・薄紫は明るい）。明るさをそろえると、色覚の型によって見分けられない組が出るため。

**決まり**

- 色はサイトに付く。サイトの選択を外しても、残ったサイトの色は変えない。
- 9サイト目からは色を作らない。灰色（`#8a929c`）の「その他」として描き、凡例とホバーの名前で読む。
- サイトを足した「合計」は、サイトの色を使わず墨色（`--ink`）で描く。
- 文字にサイトの色を使わない。サイト名は墨色で書き、横に色の丸（またはチェックボックス）を置く。
- 状態の色（§2.3）をサイトの色に使わない。サイトの色を状態に使わない。

**内訳の濃淡**

デバイス・国などの区分（1つの全体を分けたもの）には、サイトの色を使わず、墨色の濃淡4段を左から順に使う。

| 段 | 値 | 中の文字 |
|---|---|---|
| 1（`--share-1`） | `#1c2330` | 白（15.8:1） |
| 2（`--share-2`） | `#5b6574` | 白（5.9:1） |
| 3（`--share-3`） | `#a3abb5` | 墨色（6.8:1） |
| 4（`--share-4`） | `#d5d9df` | 墨色（11.1:1） |

3段目・4段目は白い面との差が小さいので、帯の中の割合・凡例・ホバーで読めるようにする。区分は4つまでにし、5つ目からは「その他」にまとめる。
- 色を変えるときは、検査をやり直してから変える（§8）。

### 2.3 状態の色

| 状態 | 文字・アイコン | 面 | 枠 |
|---|---|---|---|
| エラー | `#b42318` | `#fef3f2` | `#fecdca` |
| 注意 | `#a15c07` | `#fffaeb` | `#fedf89` |
| 成功 | `#067647` | `#ecfdf3` | `#abefc6` |

必ず、アイコンと文と一緒に出す。色だけで状態を伝えない。

### 2.4 ダークモード

今は作らない。作るときは、各色を暗い面用に選び直して検査する（明るい色を自動で反転しない）。

## 3. 文字

- **書体**: IBM Plex Sans JP（和文と英数字の両方）。和文と英数字が同じ設計で作られ、数字の幅をそろえられる。next/font で自前で配信し、外部のサーバーへは読みに行かない。読めないときは OS の標準の書体で出す。
- **太さ**: 400（本文）、500（見出し・強調・合計）、600（ページの題）。700 以上は使わない。

| 大きさ | 使うところ | 行の高さ |
|---|---|---|
| 12px | 目盛り、注記、ホバーのカード、補足 | 1.5 |
| 13px | 表 | 1.5 |
| 14px | 本文、ボタン、入力 | 1.7 |
| 16px | 区切りの見出し（グラフ・表の題） | 1.5 |
| 20px | ページの題 | 1.4 |
| 24px | 数字のカードの数字（600。幅をそろえない数字） | 1.25 |
| 36px | 合計のカードの数字（600。幅をそろえない数字） | 1.25 |

- **数字**: 表・軸・ホバーのカードでは、幅のそろった数字（`tabular-nums`）にして右に寄せる。3桁ごとに区切る（1,234）。
- **しないこと**: 英字をすべて大文字にしたラベル、見出しの一語だけ色や太さを変えること、題の上に置く小さなラベル。

## 4. 余白・形

- **余白**: 4px を単位にする（4・8・12・16・24・32）。
- **画面の幅**: 最大 1152px。左右の余白は、スマホ 16px・PC 24px。区切りと区切りの間は 24px。
- **角の丸み**: 面（表・グラフの枠・ダイアログ）8px、ボタン・入力・切り替え 6px、色の丸は真円。
- **枠**: 1px の `--border`。
- **影**: 使わない。ホバーのカードとダイアログだけ、1種類の影（`0 4px 16px rgb(28 35 48 / 0.10)`）を使う。

## 5. グラフ

dataviz（グラフの描き方の決まり）に従う。検査の方法は §8。

**形**

- 時間の推移は折れ線。名前ごとの大小（イベント名など）は横棒にし、多い順に上から並べる。系列（サイト）ごとの内訳を見せるときは、棒の中を系列の色で積み上げる。区切りは長さを変えない内側の白い線（2px）にする（すき間にすると、短い棒で区切りが棒より長くなって崩れるため）。
- 1つの全体を分けた割合（デバイス・国など）は、100% の積み上げの帯グラフにする。比べたいもの（サイト）ごとに1本ずつ縦に並べ、区分の間に 2px のすき間を空ける。帯の両端は 4px 丸める。ホバーでは、折れ線グラフと同じ形のカードに、区分・指標の名前・実数（と割合）を出す。カードはカーソルの右下に出し、右端に近いときは左に出す。
- 縦軸を2本にしない。単位の違う2つの数字は、グラフを分ける。
- 円グラフは使わない。

**線と点**

- 線は 2px、角と端は丸める。
- 各値に丸い点を出す（直径 6px、周りに面の色（白）の 1.5px の縁）。どこで折れているかを見えるようにするため（2026-11-26 利用者の決定）。白い縁で、点や線が重なっても区切りがわかる。
- ホバーした点は、直径 10px・縁 2px にして目立たせる。
- 描き始めのアニメーションはしない。

**軸と補助線**

- 補助線は横だけ。1px の実線（点線にしない）で `--grid`。軸の線は下だけ `--axis`。
- 縦軸は右。目盛りは切りのいい数（0・5・10）。1万を超えたら「1.2万」の形にする。
- 目盛りの文字は 12px・`--ink-3`・幅のそろった数字。端の目盛りが切れないだけの余白をとる。

**凡例・ホバー**

- 系列が2つ以上なら、凡例を必ず出す。どのグラフも、題のすぐ下に、色の丸と名前を横に並べる（2026-11-26 利用者の決定で位置をそろえた）。系列を選べる画面でも、凡例は見るためのもので、選ぶのは数字のカードなどのチェックボックスで行う。選んでいない系列は凡例に出さない。
- 線の端に名前や値は付けない。リアルタイムの線は近い値で重なりやすく、付けると読めなくなるため。凡例とホバーで読む。
- ホバーでは、縦線（1px・`--ink-3`）と、その時点の全系列の値を並べたカードを出す。カードは白い面・枠・影、12px。見出しは時点、行は「色の丸・名前・値」で、サイトの並び順にする。
- グラフの数字を表に切り替えて見る機能は置かない（2026-11-26 利用者の決定。dataviz の決まりでは表で見る手段を求めるが、置かない）。各時点の値はホバーのカードで読む。期間の値は、グラフとは別の数字（リアルタイムでは数字のカード）で読む。

**合計**

- 系列を足した合計の線を出すときは、墨色（`--ink`）にして、サイトの線の上に描く。
- 出し入れは、合計の数字のカードのチェックボックス「合計」で行う。出しているときは、凡例にも「合計」を並べる。合計の線は値が大きく、サイトの線が下に寄って見えるため、外せるようにする。

**絞り込み**

- 出すサイトの選択などの絞り込みは、グラフの上にまとめる。グラフの枠の中には置かない。系列ごとの数字のカードがあるときは、カードにチェックボックスを入れて選ぶ（リアルタイム。2026-11-26 利用者の決定）。
- 指標の切り替え（PV / UU）は絞り込みではないので、グラフの題の横に置いてよい。

**取り直し**

- 取り直している間は、前の数字をそのまま出し、画面の真ん中に読み込み中の印を出すだけにする（2026-11-26 利用者の決定）。数字を薄くしたり、読み込み中の枠に戻したりしない。印はクリックを下に通し、取っている間も操作できるようにする。ほかの画面から戻ったときも、前に取った数字をすぐ出してから取り直す。

## 6. 部品

| 部品 | 決まり |
|---|---|
| 主なボタン | 墨色の面に白い文字。高さ 32px。1つの区切りに1つまで（「更新」「サイトを追加」など） |
| 副のボタン | 白い面に枠（`--axis`。`--border` だと薄くてボタンに見えない） |
| 控えめなボタン | 枠なし。ホバーで `--hover` の面（ログアウト、並べ替え） |
| 削除のボタン | エラーの色の文字に、薄いエラーの面 |
| 切り替え（PV / UU） | 枠の中に並べ、選んだほうを墨色の面に白い文字にする |
| チェックボックス | サイトを選ぶときは、枠と塗りをサイトの色にする |
| 表 | 行の高さ 40px。見出しは 12px・500・`--ink-2`。数字は右寄せ・幅のそろった数字。合計の行は上に線を引き、500 |
| 数字のカード | 白い面・枠の小さなカード。上に色の丸（選べるときは色付きのチェックボックス）と名前、その下に指標名（12px・`--ink-3`）と数字（24px・600）を横に並べる。合計のカードは横幅いっぱいにし、数字を 36px にする。チェックボックスのあるカードは、カードのどこを押しても切り替わるようにし（名前のラベルの当たり判定をカード全体に広げる。読み上げの名前は名前だけにする）、ホバーで面を `--hover` にする。外した系列のカードは数字を薄くする。大きな数字は幅をそろえない（表の数字だけそろえる） |
| お知らせ | 状態の面・枠に、アイコンと文（§2.3） |
| 空のとき | 何をすればいいかと、そこへのリンク |
| 読み込み | 画面の真ん中に、回る印と「取得中…」の小さなカードを出す（動きを減らす設定のときは回さない）。前の数字はそのまま出す。まだ数字がないときも、白い枠は出さず印だけにする |
| フォーカス | 3px の半透明の墨色の輪を出す。キーボードで操作したときに必ず見える |

## 7. 書き方

- ボタンは、押すと何が起きるかを動詞で書く（「更新」「サイトを追加」「削除する」）。確かめるダイアログでも「はい」「いいえ」を使わない。
- エラーは「何が起きたか」と「どうすればいいか」を書く。謝らない。
- 数字は3桁で区切り、単位を省かない。時刻は日本時間の「14:32:05」の形。
- 同じものは同じ名前で呼ぶ。PV、UU（GA4 のアクティブユーザー）、サイト、プロパティ。

## 8. 実装と検査

- 色はすべて `web/app/globals.css` の CSS 変数で持ち、部品の中に色の値を直接書かない。サイトの色は `--series-1`〜`--series-8`、9サイト目からの灰色は `--series-other`。
- サイトの色を変えるときは、dataviz の検査スクリプトでやり直す。8色の隣り合う組と、最初の5色のすべての組の2回。

  ```bash
  node validate_palette.js "#2552aa,#c28412,#14938d,#a67ad6,#922d55,#d97230,#046a2f,#8285eb" --mode light --surface "#ffffff"
  node validate_palette.js "#2552aa,#c28412,#14938d,#a67ad6,#922d55" --mode light --surface "#ffffff" --pairs all
  ```

- グラフを変えたら、画面を開いて目で確かめる（文字の重なり、はみ出し、端の目盛り）。
